🌴 GoaScape — Discover the Magic of Goa

GoaScape is a tourism and travel guide website designed to showcase the beauty, cultural heritage, historic landmarks, and travel experiences of Goa, India.

The website provides visitors with an engaging way to explore popular destinations, discover heritage sites, browse scenic galleries, and access travel information through a clean, visually appealing interface.

🌊 Overview

GoaScape is a static, multi-page tourism website that introduces visitors to Goa's coastal beauty, cultural diversity, architecture, and historical attractions.

The project focuses on creating a user-friendly browsing experience with dedicated pages for destinations and travel-related content. It demonstrates the use of HTML for page structure, CSS for visual presentation, and JavaScript for interactive functionality.

The website is intended for travel inspiration, destination discovery, and demonstrating fundamental frontend web development skills.

✨ Features
Interactive Homepage: A welcoming landing page highlighting Goa as a travel destination.
Heritage Exploration: Dedicated pages featuring notable historical, architectural, and cultural attractions.
Destination Navigation: Easy navigation between the website's main sections.
Travel Gallery: A dedicated gallery for exploring Goa's scenic attractions.
Travel Guide: A section for useful travel-related information and tips.
Hotel Booking Interface: A frontend booking enquiry form with check-in and check-out date validation.
Destination Selection: A homepage form that lets users navigate to selected destination categories.
Date Validation: Prevents the selection of past travel dates and checks booking date order.
Responsive Navigation: A JavaScript-powered navigation menu designed to support smaller screens.
Back-to-Top Interaction: Provides a convenient way to return to the top of a page where the control is available.
Active Navigation State: Highlights the current page in the navigation menu.

🚀 Getting Started

Follow these steps to run GoaScape on your local machine.

Prerequisites

You will need:

A modern web browser such as Google Chrome, Mozilla Firefox, or Microsoft Edge.
Git, if you want to clone the repository.
A code editor such as Visual Studio Code (recommended).
1. Clone the repository
git clone https://github.com/Mohini-JHA/IT_project.git

2. Navigate to the project directory
cd IT_project

3. Open the website

Open index.html directly in your web browser.

Alternatively, if you use Visual Studio Code, open the project folder and launch index.html using the Live Server extension.

No build command or dependency installation is required for the basic static website.

⚙️ How It Works

GoaScape uses a simple frontend architecture:

HTML pages define the content and structure of each section.
CSS styling provides the website's visual design and layout.
JavaScript handles client-side interactions, navigation behavior, and form validation.
Internal links connect the homepage, heritage pages, gallery, hotel interface, and travel guide.

This structure keeps the project straightforward to understand, run, and extend.

🏨 Hotel Booking Demo

The hotel page contains a frontend booking enquiry interface with basic validation for check-in and check-out dates.

Important: This is a demonstration of frontend form behavior. It does not make actual hotel reservations, process payments, or connect to a live hotel booking service.

A future version could integrate a backend API and a database to support real reservation workflows.
